## 🚀 Key Architectures & Features

- **Cuberto & Unseen-Style 3D WebGL Gallery:** High-performance cylindrical carousel with custom GLSL shaders and smooth lerp scrolling on desktop; native 120Hz touch cards for mobile.
- **Dennis Snellenberg Editorial About Section:** Minimalist typography, dual-column editorial layout, and floating executive portrait.
- **Instant Optimistic Contact Dispatch:** Non-blocking 350ms tactile feedback with asynchronous background Gmail delivery via FormSubmit (`keepalive: true`) and zero perceived wait time.
- **Zero-Data-Loss Local Inbox (`/inbox`):** Server-side persistence to local storage (`data/contact_messages.json`) ensuring every lead is preserved even during external network dropouts.
- **Strix Security Audited:** Rigorously tested with automated penetration testing and dependency vulnerability scanning (OWASP WSTG compliance, Next.js 15.3.9 patched).

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/sakilahammed-dev/official-portfolio.git
cd official-portfolio

# Install dependencies (using Bun or npm)
bun install
# or
npm install

# Start development server
bun run dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
